# Edi Metronome / Edi Metronom

A browser-based metronome built in a single HTML file. Customize your tempo, combine time signatures, edit beat accents and save your rhythms. The application interface is in Turkish.

Tek HTML dosyasıyla çalışan tarayıcı tabanlı metronom. Tempoyu ayarlayın, farklı ölçüleri birleştirin, vuruş vurgularını düzenleyin ve ritimlerinizi kaydedin. Uygulama arayüzü Türkçedir.

## Features / Özellikler

* Adjustable tempo from 30 to 300 BPM and tap tempo.
  30–300 BPM arasında ayarlanabilir tempo ve dokunarak tempo belirleme.
* Multiple measures, custom time signatures and beat grouping.
  Birden fazla ölçü, özel ölçü seçimi ve vuruş gruplama.
* Strong, medium, weak and silent beats.
  Güçlü, orta, zayıf ve sessiz vuruşlar.
* Rhythmic subdivisions with note and syllable guides.
  Nota ve hece gösterimleriyle ritmik alt bölümler.
* Save rhythms and import/export JSON backups.
  Ritim kaydetme ve JSON yedeklerini içe/dışa aktarma.
* Light and dark themes, full-screen beat view and keyboard shortcuts.
  Açık ve koyu tema, tam ekran vuruş görünümü ve klavye kısayolları.

## Getting Started / Başlangıç

Open `index.html` in a modern browser. Set your tempo and time signature, then press **Başlat** to start playback. No installation or build step is required.

`index.html` dosyasını güncel bir tarayıcıda açın. Tempo ve ölçüyü ayarlayıp **Başlat** düğmesine basın. Kurulum veya derleme işlemi gerekmez.

## Saved Rhythms / Kayıtlı Ritimler

Settings and saved rhythms are stored locally in your browser using `localStorage`. They do not automatically sync between devices or website addresses. Export your rhythms as JSON to back them up or transfer them.

Ayarlar ve kayıtlı ritimler, `localStorage` kullanılarak tarayıcınızda saklanır. Cihazlar veya farklı site adresleri arasında otomatik eşitlenmez. Yedeklemek veya taşımak için ritimlerinizi JSON olarak dışa aktarın.

## Technology / Teknoloji

HTML, CSS, JavaScript and Web Audio API. No external libraries or backend required.

HTML, CSS, JavaScript ve Web Audio API. Harici kütüphane veya sunucu taraflı uygulama gerektirmez.
